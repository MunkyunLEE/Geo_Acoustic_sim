브라우저 확인(헤드리스 Chromium, Playwright 마우스 조작): 본체 드래그 이동(5,5,1)→(8,5.5,1), Ctrl+Z/Ctrl+Shift+Z, Shift 드래그 수직 이동(z 1→2.5), 면 선택 후 기즈모로 밀기(박스 x폭 1→1.5 m, 실행 취소로 복원), 꼭짓점 선택 후 z 방향 당기기(z 최대 0.5→1, 취소로 복원), 모서리 선택(꼭짓점 2개). 그 밖에: 박스 룸 차수 0/2/3 결과 변화, 전 면 소산 시 직접음만, 차폐벽 뒤 회절 ON/OFF, 점/면 파면, STL 가져오기.

한계(STEP 2):

- 회절은 직접음이 가려진 곳에만 적용되어 그림자 경계에서 약 4.8 dB 불연속이 있습니다. 반사 경로의 회절은 없습니다.
- ISO/Maekawa 식은 깊은 그림자에서 Fresnel 참조해보다 1.2~2.9 dB 덜 감쇠합니다.
- 정반사만 구현했고(산란분 s는 STEP 3) 후기 잔향이 없어 닫힌 방의 레벨이 낮게 나옵니다.
- 성분은 비간섭 에너지 합입니다. 약 100 Hz 이하는 기하음향 범위를 벗어납니다.
- 이 값은 어떤 실측·벤치마크와도 검증되지 않았습니다. 공기 흡음 표는 OCR 추출본과 대조했으므로 규격 원문 재확인이 필요합니다.

- 꼭짓점·모서리·면 편집은 면이 평면이 아니게 되거나 서로 교차해도 막지 않습니다(자체 교차 검사 없음). 곡면(원기둥 옆면)은 삼각형 단위로 선택됩니다.
- 다중 음원은 비간섭 에너지 합입니다. 투과는 지원하지 않아 얇은 서페이스도 완전 차폐입니다.
- GIF 출력과 에코그램은 STEP 5, 투과는 STEP 6에서 추가했습니다.

## STEP 4

| 테스트 파일                  | 확인 내용                                                                                                                                                                                        |

| `tests/unit/diffuse.test.ts` | 코사인 샘플러(E[cosθ]=2/3, P(cosθ≥0.5)=0.75)·구면 샘플러, 자유장 (1 m/r)² (5 %)·공기 흡음 포함, 에너지 수지 1e-9, s=1 닫힌 방 참조해 (8 %), s=0 이미지 음원 일치·이중 집계 없음 (5 %), 시드 재현 |

브라우저 확인(헤드리스): Run → 진행률 표시 → 결과 표에 "확산 ±SE" 열, 5만 레이 계산 중 "계산 취소" → 즉시 중단·이전 결과 유지, 확산 끔 → 이전 방식 결과.

한계(STEP 4):

- 확산 성분은 통계 추정입니다. 기본 밴드당 5,000 레이에서 박스 룸 수신점의 표준오차는 약 ±0.1 dB(통계만)이며 모델 오차는 포함하지 않습니다.
- 수신 반경 민감도와 레이 수 수렴은 STEP 5에서 측정했습니다(아래).
- 슬라이스의 확산 성분은 복셀(긴 변 40셀) 보간이라 해상도가 거칩니다. 얇은 객체 뒤처럼 작은 구조의 확산장은 표현하지 못합니다.
- 최대 반사 횟수(기본 60)·하한 에너지(10⁻⁶)에서 추적을 멈춰 흡음이 매우 낮은 방은 잔향 꼬리가 잘립니다.
- 확산 반사 경로의 회절은 없습니다. 에코그램·시간 분해는 STEP 5입니다.
- 닫힌 방의 레벨은 확산 성분이 지배하므로 슬라이스가 거의 균일하게 나옵니다. 결과는 실측·타 상용 도구와 대조하지 않았습니다.

| `tests/unit/transmission.test.ts` | 정반사 계수 (1−α−τ)(1−s), α+τ>1 검증 오류, 직접음 τ·τ² 곱, TL 없음=완전 차폐, MC 투과 이득 τ/r², 이중 집계 없음, 투과 포함 에너지 수지, 에코그램 구간 합=총 이득·피크 시각 ≈ r/c, 면 입사 ≈ 1/r² |
| `tests/unit/export.test.ts`       | 결과/에코그램/슬라이스 CSV 형식, GIF 헤더(GIF89a)                                                                                                                                                |

브라우저 확인(헤드리스): 면음원 추가 → Inspector에 Lw·표본점 입력, Run → 에코그램 SVG, CSV 3종·PNG·GIF 다운로드(60프레임, 시각·컬러바 표기 확인), 콘솔 오류 없음.

수렴 측정 (박스 룸 10 m, α=0.2, s=0.5, 1 kHz, 반경 0.5 m, 시드 8개, 확산 성분 dB): 밴드당 레이 1,000 → 50,000에서 표준편차 0.84 → 0.08 dB, 평균 −5.53 ~ −5.39 dB. 반경 0.25 → 1.5 m (20,000 레이): 표준편차 0.31 → 0.03 dB, 평균 −5.49 ~ −5.44 dB.

한계(STEP 5·6):

- 투과: 이미지 음원 반사 다리는 투과 면을 막힌 것으로 처리, 파면 재생 광선은 투과를 무시합니다.
- 면음원은 등방 표본점(최대 5×5)이며 전방 지향성·간섭이 없습니다. 비간섭 합입니다.
- 에코그램의 회절 성분은 가장 짧은 우회 경로 시각에 모아 표시합니다.
- 표면 입사 에너지는 MC 전용(확산 계산 필요)이고 작은 삼각형에서는 잡음이 큽니다. 영역 경계면에는 적용하지 않습니다.
- 수렴 측정은 한 장면·한 밴드이며, 반경 민감도는 확산장이 균일한 곳에서만 작았습니다.
- 마우스 조작·GIF는 헤드리스로만 확인했습니다. 결과는 실측과 대조하지 않았습니다.
