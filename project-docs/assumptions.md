# 가정과 규약 (STEP 0 기준)

물리 식과 근거는 `public/docs/physics.html`(웹: `/docs/physics.html`)이 기준입니다. 이 문서는 코드에 반영된 규약만 요약합니다.

## 단위와 좌표계

- 솔버 내부는 SI (m, s, Hz, W, Pa). 임포트 경계에서 mm/cm/m → m로 한 번만 변환합니다 (`src/solver/core/units.ts`).
- 좌표계는 Z-up 우수 좌표계이며 Rhino와 같습니다. 뷰포트 카메라 up 벡터를 Z로 둡니다.
- 에너지·파워는 선형량으로 다루고 dB는 표시할 때만 변환합니다 (`src/solver/core/db.ts`).
- 음원은 밴드별 파워 레벨 Lw [dB re 1 pW]로 입력합니다. Lp(음압 레벨)와 혼용하지 않습니다.

## 데이터 규약

- `Scene`은 `schemaVersion`을 가지며 현재 1입니다. 형식이 바뀌면 올립니다.
- 모든 재료 계수(α, s)는 밴드별 0~1입니다. 현재 재료는 **예시 값**이며 실측 데이터가 아닙니다 (`isExample: true`).
- 음원 타입은 점음원/면음원 구분형입니다. 면음원은 타입만 있고 계산은 STEP 5입니다.
- 수신기는 크기 0의 점이 아니라 반경 `radius`를 가진 수신 구입니다. 기본값 0.5 m는 초기 가정이며 STEP 3에서 확정합니다.
- 표면은 양면으로 취급합니다 (감김 방향 무관).
