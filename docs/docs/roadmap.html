한눈에 보기

STL/OBJ 불러오기 → 점음원 놓기 → Run → 파면이 퍼지고 튕기는 모습과 상대 레벨 컬러맵 확인

  • 브라우저 전용(GitHub Pages). 서버·로그인 없이 동작하고, 무거운 케이스만 나중에 선택적으로 백엔드로 보냅니다.
  • 결과는 절대 SPL이 아니라 음원 대비 상대 레벨입니다. 자유장 1 m 지점 = 0 dB 기준입니다.
  • 이 도구는 스크리닝용 근사 해석입니다. 정밀 해석(Wave6 등) 전에 "어디가 얼마나 세지고 약해지는가"를 빠르게 보는 용도입니다.
  • 모든 STEP은 구현 → 해석해 검증 → 보고 → 승인 순서로 진행하며, 승인 없이 다음 STEP으로 넘어가지 않습니다.

STEP 0. 골격

  • 구현
  • Vite + React + TypeScript + Three.js 프로젝트 (Z-up, 단위 m)
  • 타입: Scene, Source(점/면 구분형), Material, Receiver, OctaveBand과 단위 변환 함수
  • 3D 뷰포트(궤도 카메라, 그리드), 샘플 장면(박스 룸, 지면+벽)
  • Vitest, ESLint/Prettier, docs/ 문서
  • GitHub Pages 설정: Vite base: '/acoustic-simulator/', deploy.yml
  • 문서 연동: 앱 헤더에 "물리 문서", "로드맵" 링크. 기능별 ⓘ 아이콘은 physics.html의 앵커(#receiver 등)로 이동
  • 합격 기준: 빌드 성공, /acoustic-simulator/ 하위 경로에서 자산·워커·문서 링크 정상, 백엔드 요청 없음, 테스트 통과
  • 산출물: 프로젝트 zip + 실행/검증 방법

STEP 1. 임포트 + 직접음

  • 구현
  • STL/OBJ 임포트 (mm/cm/m 선택 → m 변환), 메시 검사(퇴화 삼각형 등)
  • 삼각형 BVH (자체 구현, three.js 비의존)
  • 점음원(밴드별 Lw), 수신점, 가시선 판정, 자유장 감쇠 + 공기 흡음
  • 수평 단면 상대 레벨 컬러맵 (직접음, 해석식)
  • 최소 파면 애니메이션: 구형 파면 입자, 재생/일시정지, 시간 슬라이더
  • 검증
  • 거리 2배 → −6.02 dB (공기 흡음 제외)
  • 불투명 차폐 시 직접음 0
  • 대역 합산은 선형 에너지 합, 근접 수신기에서 NaN/Infinity 없음
  • BVH 결과 = 완전 탐색 결과

STEP 2. 정반사 + 회절 (박스 룸)

  • 구현
  • 해석 영역(기본 10 m 정육면체 박스 룸), 면별 경계 조건: 반사(재료 α) / 소산(α=1, 나간 광선 소멸)
  • STL/OBJ 입력란을 패널 상단으로 이동, 임포트 메시는 영역 안의 객체
  • 이미지 소스 정반사(1~3차, 기본 2차), 경로를 실제 삼각형 위에서 검증
  • 회절: ISO 9613-2 차폐 보정(Dz, 단일 20 dB / 이중 25 dB 상한), 가려진 수신점에만 적용
  • 파면 애니메이션이 정반사를 따라가며, 점 / 면 표시 선택
  • 결과 표에 직접·반사·회절 성분 분해
  • 검증
  • 이미지 거리(평행 벽 9, 11, 15, 25 m), 단일 반사 에너지 (1−α)(1−s)/d², α=1 → 반사 0
  • 이미지 경로의 벽 차폐 무효 처리, 차수 증가 시 짧은 경로 유지
  • Fresnel 반평면 참조해(scipy 사전 계산)와 비교, ISO 식은 0.3~3 dB 덜 감쇠
  • 경로차 δ 해석값(두께 0 / 0.4 m 벽, 좁은 기둥), 상한, 저주파 ≥ 고주파 이득
  • 파면 색 = 이미지 소스 레벨과 같은 식, 고정 시드 재현
  • 알려진 한계: 가려진 곳에만 회절 적용(그림자 경계 약 4.8 dB 불연속), 반사 경로의 회절 없음, 파면에 회절파 없음, 확산 반사·후기 잔향 없음(레벨이 낮게 나옴), 약 100 Hz 이하 비신뢰
  • 회절은 원래 STEP 5 후보였으나 사용자 승인으로 STEP 2에 포함

STEP 3. 장면 편집기 + Run (2026-10-21 개정)

작업 흐름: 장면을 직접 구성 → Run → 결과 확인 → 재생/멈춤. 편집 중에는 계산·미리보기를 하지 않습니다.

  • 3-A 편집 모델 (순수 로직)
  • 객체 = 서페이스(열린 면 허용, 솔리드 불필요) + 변환(이동·회전·크기) + 재료(α, s 밴드별)
  • 프리셋: 반사벽 / 소산벽(α=1) / 흡음재 / 장애물. 값은 사용자가 수정 가능. 투과 속성은 지원하지 않음(STEP 6)
  • 생성: 폴리라인 → extrude(벽), 닫힌 폴리라인 → 면, 기본 도형(박스, 평면, 원기둥)
  • 임포트 STL/OBJ도 같은 객체로 취급, 장면 JSON 저장/불러오기
  • 3-B 편집 UI
  • 3D 뷰에서 객체·음원·수신점 선택 → 속성 패널
  • 이동·회전·크기 조절: 숫자 입력과 기즈모 동시 지원, 그리드 스냅 on/off
  • 폴리라인 그리기 도구(평면도 클릭), extrude 높이 입력, 복제·삭제
  • 꼭짓점·모서리·면 편집, 실행 취소/다시 실행, Shift 수직 이동 구현 완료 (D31)
  • 3-C Run 흐름
  • Run 버튼으로만 계산 (직접 + 정반사 + 회절), 결과는 스냅샷으로 보관
  • 편집하면 결과를 "오래된 결과"로 표시, 재생/멈춤/시간 이동은 결과에만 연결
  • 검증: 변환 후 좌표 해석값, extrude 면 수·법선·면적, 장면 JSON 왕복 일치, 편집 중 계산 호출 없음, 기존 솔버 테스트 유지
  • 합격 기준: 객체를 만들고 배치하고 Run해서 결과를 재생까지 막힘 없음

STEP 4. 확산 산란 + 수신기 추정자 (구현 완료, 승인 대기)

  • 구현
  • 산란 계수 s(f), 코사인 가중(램버트) 샘플러, 시드 고정 난수, 확률적 분기(확률 s로 확산, 아니면 정반사)
  • 수신 구 track-length 추정자(수신점) + 3D 복셀 누적(슬라이스), 이중 집계 방지 규칙: 확산을 겪은 경로 + 이미지 음원 차수를 넘는 정반사 경로만 MC가 집계 (물리 문서 21장)
  • 밴드별 독립 추적, Web Worker, 진행률·취소, Run 설정(확산 켜기/끄기, 밴드당 레이 수, 최대 반사 횟수, 시드)
  • 배치 8개 기반 표준오차(±dB) 표시
  • 검증 (자동 테스트)
  • 에너지 수지: 흡수 + 공기 + 잔여 = 방출 (1e-9)
  • s=0: 이미지 음원(≤N차) + MC(>N차) = MC 전체, MC 추정자 ≈ 이미지 음원 (5 % 이내)
  • s=1 닫힌 방 참조해 16π(1−α)/(Sα) (8 % 이내), 램버트 샘플러 분포
  • 자유장: 추정자 = (1 m / r)² (5 % 이내), 공기 흡음 포함
  • 같은 시드 → 같은 결과
  • 남은 항목: 수신 반경 민감도와 레이 수 수렴 곡선은 체계적으로 측정하지 않음 (STEP 5 프리셋 정할 때 측정), 실측·타 도구 대조는 없음

STEP 5. 결과 + 출력

  • 구현: 수신점 에코그램, 표면 입사 에너지 컬러, 프리셋 Preview/Normal/High, 재생 결과 GIF 출력, CSV/PNG 내보내기
  • 합격 기준: 처음 쓰는 사람이 장면 구성 → Run → 결과 확인 → GIF 저장까지 막힘 없음

STEP 6. 선택 모듈 (모두 기본 OFF)

  • 구현: 면음원(표본점 분할), 투과(TL → τ, α+τ ≤ 1, 재료 속성 추가)
  • OFF 상태의 결과는 STEP 5와 동일해야 합니다.

STEP 7. 성능 + 선택적 백엔드

  • 구현: 삼각형 수·레이 수·반사 수·수신기 격자별 벤치마크, 공간 가속, 병목이 확인될 때만 WASM·백엔드
  • 로컬과 원격의 결과 스키마를 동일하게 유지합니다.

결과 화면 구성 (3개 뷰)

뷰 내용 도입
A. 정상상태 컬러맵 수신기 높이 수평 단면의 상대 레벨, 밴드 선택/합산, 표면 입사 에너지 STEP 1 (직접음) → STEP 3
B. 파면 애니메이션 구형 파면이 퍼지고 반사되며 색이 변하는 재생, 슬로모션·시간 슬라이더 STEP 1 (최소) → STEP 5
C. 에코그램 수신점의 시간별 도달 에너지 (직접음, 초기 반사, 후미) STEP 4
  • 세 뷰는 같은 추적 데이터에서 만들어지므로 숫자가 서로 모순되지 않습니다.
  • 파면 애니메이션은 압력 파형이 아니라 에너지 패킷의 전파입니다. 위상, 간섭, 회절은 보이지 않습니다.
  • 입자 색은 입자가 가진 에너지가 아니라 그 위치의 국소 에너지 밀도입니다. 거리 감쇠는 입자 에너지 감소가 아니라 입자 밀도 감소로 나타납니다.

검증·정확도 정책

테스트 계층은 다음과 같고, 실패한 테스트를 조용히 우회하지 않습니다.

  1. 단위 테스트: 벡터, 교차, 법선, dB 변환, 샘플링
  2. 해석 테스트: 자유장 감쇠, 반사각, 이미지 소스
  3. 보존 테스트: 흡수·반사·투과 에너지 수지
  4. 수치 테스트: 레이 수, 수신기 크기, 장면 크기에 대한 수렴
  5. 기준 테스트: 단순 기준 형상, 이후 실측·신뢰 가능한 소프트웨어와 비교
  6. 회귀 테스트: 고정 장면 + 고정 시드 → 재현 가능한 결과

계획 목표치 (달성 주장이 아님): 자유장 1 dB 이내, 단순 반사 2 dB 이내, 복합 다중 반사 3 dB 이내, 도심 차폐 영역은 회절 도입·독립 검증 후 5 dB 이내를 목표로 둡니다. "80%" 지표는 검증 데이터와 판정 기준을 정한 뒤에만 사용합니다. 이 도구의 출력은 상대 레벨이므로 허용 오차도 상대 레벨 기준으로 평가합니다.

범위 밖 (첫 릴리스)

  • 위상·간섭, 실내 모드, FEM/FDTD 같은 파동 해석
  • 정확한 저주파 회절, 대기 굴절, 이동 음원, 기상 조건
  • 다층 투과, 클라우드·인증·DB, AI/ML
  • 이 모두는 사용자가 명시적으로 요청하기 전에는 추가하지 않습니다.

배포와 문서 연동

  • 저장소 이름은 acoustic-simulator이고 Vite base는 /acoustic-simulator/입니다.
  • public/docs/의 문서가 dist/docs/로 복사되어 https://<계정>.github.io/acoustic-simulator/docs/physics.html로 열립니다.
  • 앱에서 문서로 가는 링크는 아래처럼 BASE_URL 기반으로 만들어 하위 경로에서도 깨지지 않게 합니다.
const docsUrl = (anchor = '') => `${import.meta.env.BASE_URL}docs/physics.html${anchor}`; // 문서 URL (앵커 선택)
// 사용 예: <a href={docsUrl('#receiver')} target="_blank" rel="noopener">ⓘ</a>

  • 실제 GitHub Pages 배포는 이 환경에서 확인할 수 없습니다. 빌드와 npm run preview 기준의 하위 경로 동작까지만 검증해 전달하고, 실배포 확인은 사용자께 부탁드립니다.

진행 방식

  • 매 STEP 종료 시 보고 양식을 따릅니다: A 목표·상태 / B 변경 파일 / C 물리·알고리즘 / D 실행 명령 / E 테스트 결과(예상값 vs 실제값, PASS/FAIL) / F 수동 확인 방법 / G 한계·위험 / H 다음 STEP 제안.
  • 물리, 단위, 가정, 아키텍처, 합격 기준은 임의로 바꾸지 않고, 바꿔야 하면 근거와 함께 먼저 제안해 승인을 받습니다.
  • 결정 사항은 docs/decisions.md에 기록합니다.
