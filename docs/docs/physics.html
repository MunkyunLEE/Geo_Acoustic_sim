물리 기초와 알고리즘

3D 기하음향 시뮬레이터 · 문서 v1.1 · 2026-10-21 · 앱 전체에 공통 적용되는 식과 알고리즘의 기준 문서입니다.

이 도구는 기하음향 근사 기반의 스크리닝 도구입니다. 결과는 절대 SPL이 아니라 음원 대비 상대 레벨(자유장 1 m = 0 dB)이며, 위상·간섭·회절은 계산하지 않습니다. 정밀 해석 전에 "어디가 얼마나 세지고 약해지는가"를 빠르게 보는 용도입니다.

1. 좌표계와 단위

  • 솔버 내부는 SI 단위(m, s, Hz, W, Pa)만 사용합니다. 기준식
  • 좌표계는 Z-up 우수 좌표계이며 Rhino와 같습니다. Three.js의 기본(Y-up)과 달라서 뷰포트에서 카메라 up 벡터를 Z로 설정합니다. 설계 선택
  • STL/OBJ의 길이 단위(mm, cm, m)는 임포트 경계에서 한 번만 m로 변환합니다. 임포트 시 단위를 사용자가 확인하도록 합니다.
  • 에너지·파워는 선형량으로 저장하고, dB 변환은 출력 시점에만 합니다. dB 값끼리 직접 더하지 않습니다.
  • 표면은 양면으로 취급합니다. 레이가 들어온 쪽으로 법선을 뒤집어 사용하므로 삼각형 감김 방향(winding)에 영향받지 않습니다.

3. 레벨과 dB 연산

Lw = 10 log10(W / W0), W0 = 10−12 W (3.1)
Lp = 20 log10(prms / p0), p0 = 2×10−5 Pa (3.2)
Ltot = 10 log10 ( Σi 10Li/10 ) (3.3) 같은 레벨 두 개의 합 = +10 log102 ≈ +3.01 dB. 에너지 합산이 원칙이며 dB 값을 그대로 더하지 않습니다.

Lw(음원 파워)와 Lp(특정 위치의 음압)는 서로 다른 양이므로 절대 혼용하지 않습니다. 기준식

4. 점음원, 거리 감쇠, 상대 레벨

4.1 자유장 점음원

I(r) = W · Q / (4π r²) (4.1) Q = 지향 계수. 무지향 음원은 Q = 1. 지면은 별도 표면(메시)으로 두므로 항상 구면 확산(4π)을 사용합니다.
Lp = Lw + 10 log10( Q / (4π r²) ) + 10 log10( ρc / 400 ) (4.2) ρc ≈ 400 Pa·s/m 이면 Lp ≈ Lw − 20 log10 r − 11 dB (Q = 1). 마지막 항은 20 °C에서 약 +0.1 dB로 작습니다.
ΔL = −20 log10( r2 / r1 ) (4.3) 거리가 2배가 되면 −6.02 dB (공기 흡음 제외).

기준식 단, r → 0에서 발산하므로 해석식 평가에서는 rmin(기본 0.1 m, 설계 선택)으로 거리를 하한 처리해 NaN/Infinity를 막습니다.

4.2 상대 레벨 (이 앱의 표시 기준)

해석이 근사이므로 절대 레벨 대신 음원 대비 얼마나 세지고 약해지는가를 표시합니다. 기준은 "같은 음원의 자유장 1 m 지점"입니다.

gb(x) = 4π · Ib(x) / Wb (4.4) 밴드 b의 무차원 전달함수. 자유장 1 m에서 정확히 1입니다.
Lrel,b(x) = 10 log10 gb(x) (4.5)
Lrel,tot(x) = 10 log10 ( Σb Wb gb(x) / Σb Wb ) (4.6) 광대역 합. A 가중을 쓰면 Wb 대신 Wb·10Ab/10을 분자·분모에 똑같이 적용합니다.
  • 한 밴드만 볼 때는 Lw 값과 무관합니다. 광대역으로 합칠 때만 음원 스펙트럼(밴드별 Lw 비율)이 영향을 줍니다.
  • 자유장에서 Lrel(r) = −20 log10 r − Aair(r)입니다. 1 m보다 가까우면 양수가 되므로 컬러바는 0 dB 위쪽을 잘라서 표시합니다.
  • 기본 컬러바 범위는 0 ~ −60 dB이며 고급 설정에서 바꿀 수 있습니다. 설계 선택

면음원(STEP 5)은 면 위 표본점으로 나누어 W를 분배한 점음원의 합으로 다루며, 위 식을 그대로 재사용합니다.

5. 공기 흡음과 음속

Aair,b(L) = αb · L [dB], τair,b(L) = 10−αb L / 10 (5.1) L은 반사를 포함한 누적 경로 길이입니다. 모든 경로(직접·반사·확산)에 동일하게 적용합니다.
  • αb는 주파수, 온도, 상대습도, 기압의 함수이며 ISO 9613-1로 계산합니다. 경험계수
  • 기본 가정은 20 °C, 상대습도 50 %, 101.325 kPa이고 고급 설정에서 변경합니다. 설계 선택
  • 옥타브 밴드에는 중심 주파수의 α값을 대표값으로 씁니다. 대역폭 내 변화를 무시하므로 고주파에서 근사입니다.
  • STEP 1에서 ISO 9613-1 식을 구현한 뒤 표준에 실린 표의 값과 대조해 검증합니다. 표의 값을 검증 없이 코드에 하드코딩하지 않습니다.
c ≈ 331.3 · ( 1 + T / 273.15 )1/2 [m/s], T [°C] (5.2) 근사 20 °C에서 약 343.2 m/s. 도달 시간 t = L / c 계산에 사용합니다.

6. 기하 처리: 교차, BVH, 가시선

6.1 레이–삼각형 교차 (Möller–Trumbore)

레이 O + td, 삼각형 꼭짓점 v0, v1, v2일 때 아래 순서로 계산합니다. 기준식

e1 = v1 − v0;   e2 = v2 − v0
h  = d × e2;    a  = e1 · h            // |a| < ε 이면 평행 → 교차 없음
f  = 1 / a;     sv = O − v0
u  = f (sv · h);        u < 0 또는 u > 1 이면 기각
q  = sv × e1
v  = f (d · q);         v < 0 또는 u + v > 1 이면 기각
t  = f (e2 · q);        t > t_min 이면 교차 (교차점 P = O + t d)
n = ( e1 × e2 ) / | e1 × e2 | ; n · d > 0 이면 n ← −n (6.1) 양면 처리: 법선이 항상 들어오는 레이와 마주 보도록 뒤집습니다.

6.2 자기 교차 방지

반사 후 새 레이의 원점을 P + εn으로 옮기고 tmin = ε을 사용합니다. ε = 10−6 × (장면 바운딩 박스 대각선 길이)를 기본값으로 하며, 장면 크기에 맞춰 스케일되도록 합니다. 연산은 float64로 하고, 값 조정은 STEP 2의 "자기 교차 없음" 테스트로 확인합니다. 설계 선택

6.3 BVH와 가시선 판정

  • BVH는 AABB 트리이며 가장 긴 축의 중앙값으로 분할하고, 잎 노드는 삼각형 4개 이하로 둡니다. 탐색 복잡도는 대략 O(log M)입니다. 설계 선택
  • 가장 가까운 교차 질의: 반사·산란 추적에 사용합니다.
  • 임의 교차(any-hit) 질의: 선분 A→B의 가시선 판정에 사용하며, 하나라도 맞으면 즉시 종료합니다. 레이 tmax = |B − A| − ε입니다.
  • 검증: 무작위 레이 수천 개에 대해 BVH 결과가 완전 탐색(brute force) 결과와 같은 삼각형·같은 t를 내야 합니다.

7. 정반사와 이미지 소스

7.1 반사 벡터

dr = d − 2 ( d · n ) n (7.1) 기준식 |dr| = 1 이고, 법선 성분만 부호가 바뀌며 접선 성분은 유지됩니다(입사각 = 반사각).

7.2 반사 시 에너지

표면에 입사한 에너지 중 α(f)는 흡수되고 나머지가 반사됩니다. 반사된 에너지를 정반사와 확산으로 나누는 방식은 8장에서 다룹니다.

Er = ( 1 − αb ) · Einc (7.2)

7.3 이미지 소스 방법 (Allen & Berkley)

평면 위의 한 점 p0와 법선 n이 주어지면, 음원 S의 거울상 S′와 반사 경로 길이는 다음과 같습니다. 기준식

S′ = S − 2 ( ( S − p0 ) · n ) n (7.3)
L = | R − S′ | , t = L / c (7.4) 수신점 R까지의 펼친 경로 길이. 실제 반사 경로의 길이와 같아야 합니다(검증 항목).
Ib = Wb / ( 4π L² ) · Πj ( 1 − αj,b )( 1 − sj,b ) · 10−αair,b L / 10 (7.5) j는 거친 반사면의 순번. 정반사로 남는 비율은 (1 − s)(1 − α)이므로 산란 계수 s가 곱해집니다(8장).

경로 유효성 검사 (모두 만족해야 경로가 존재합니다)

  1. S와 R이 반사 평면의 같은 쪽에 있다.
  2. 선분 S′R이 평면과 만나는 점 P가 해당 삼각형 안에 있다.
  3. 구간 S→P와 P→R이 다른 삼각형에 가로막히지 않는다(any-hit, 반사 삼각형 자신은 제외).

k차 반사는 이미지의 이미지를 만들고, 검사는 R에서 거꾸로 거슬러 올라가며 각 반사점을 확인합니다. 삼각형 수가 M이면 이미지가 Mk개로 늘어나므로, 기본은 1~2차까지만 이미지 소스를 쓰고(Kimg, 설계 선택) 동일 평면의 삼각형을 묶고 거리·에너지 임계로 가지치기합니다. 그 이상은 몬테카를로로 처리합니다(9장).

8. 확산 산란

8.1 에너지 분배

산란 계수 s는 반사된 에너지 중 확산으로 가는 비율이며 추가 에너지원이 아닙니다. 기준식

Eabs = α Einc, Espec = ( 1 − s )( 1 − α ) Einc, Ediff = s ( 1 − α ) Einc (8.1) Eabs + Espec + Ediff = Einc (0 ≤ α, s ≤ 1)

극한 검증: s = 0이면 전부 정반사, s = 1이면 전부 확산, α = 1이면 반사 에너지 없음, α = 0이면 흡수 없음.

8.2 코사인 가중 반구 샘플링 (Lambert)

확산 반사 방향은 Lambert 분포를 따릅니다. 근사 실제 표면의 산란 지향성은 더 복잡합니다.

p( ω ) = cos θ / π (반구 위, ∫ p dω = 1) (8.2)
ξ1, ξ2 ~ U(0,1)                          // 시드 고정 난수
r = √ξ1;   φ = 2π ξ2
x = r cos φ;   y = r sin φ;   z = √(1 − ξ1)   // z = cos θ (국소 좌표)
t = normalize( cross( n, a ) )                // a: n과 가장 덜 평행한 축
b = cross( n, t )
d_diff = x t + y b + z n                      // 세계 좌표 방향

Lambert BRDF(1/π)에 cos θ를 곱하고 p(ω)로 나누면 가중치가 1이 되어, 샘플링에 따른 추가 보정이 필요 없습니다(편향 없음).

8.3 확률적 분기와 밴드별 추적

  • 표면 충돌마다 ξ ~ U(0,1)을 뽑아 ξ < s이면 확산, 아니면 정반사를 선택하고 어느 경우든 P ← (1 − α) P를 적용합니다. 기댓값이 식 (8.1)과 일치하므로 편향이 없습니다. 설계 선택
  • s와 α가 밴드마다 다르므로 밴드별로 독립 추적합니다. 레이 수는 밴드당 기준입니다(결정 D15, STEP 3에서 확정).
  • 각 경로에 nSpec(정반사 횟수)과 nDiff(확산 횟수)를 기록합니다. 9장의 중복 집계 방지에 사용합니다.
  • 난수는 시드 고정 PRNG(예: mulberry32)를 쓰고, 밴드별 시드는 (사용자 시드, 밴드 번호)에서 결정론적으로 만듭니다. 같은 장면·같은 시드는 같은 결과를 냅니다.
  • 최대 반사 횟수 Kmax(Normal = 5)에서 종료합니다. 에너지 임계값으로 조기 종료하면 약간의 편향이 생기므로, 사용할 경우 임계값을 결과에 표시합니다.

9. 수신기 추정자 (가장 중요한 설계 리스크)

크기가 0인 점에는 레이가 맞을 확률이 0이므로, 레이가 맞은 횟수를 세는 것은 SPL이 아닙니다. 이 앱은 유한한 수신 영역을 지나가는 경로 길이를 모아 에너지 밀도를 추정합니다(track-length 추정자). 설계 선택 구현 후 STEP 3에서 검증합니다.

9.1 수신 구 track-length 추정자

레이 i가 파워 Pi를 연속적으로 운반한다고 보고, 수신 영역(부피 V)을 지나는 구간 길이를 ℓi라 하면, 그 영역에 머무는 에너지는 Pi ℓi / c입니다.

w = ( 1 / ( c V ) ) Σi Pi ℓi (9.1)
Ieq = w c = ( 1 / V ) Σi Pi ℓi , V = ( 4/3 ) π Rr³ (9.2)
gb = 4π Ieq,b / Wb → Lrel,b = 10 log10 gb (9.3) 식 (4.4), (4.5)와 연결됩니다. 1차 레이의 파워는 Pi = Wb/N (구 전체 균일 샘플링, z = 1−2ξ1, φ = 2πξ2)입니다.

자유장에서의 확인. 구가 거리 r에 있고 Rr ≪ r이면, 구를 지나는 레이의 비율은 Rr² / (4r²)이고 구의 평균 현 길이는 4V/S = 4Rr/3입니다. 따라서 Σℓ = N Rr³ / (3r²)이고, 식 (9.2)에 넣으면 아래처럼 해석해가 나옵니다.

Ieq = ( W / N ) · N Rr³ / ( 3 r² ) / ( 4π Rr³ / 3 ) = W / ( 4π r² ) (9.4)
  • 수신 구는 부피 평균이므로 Rr/r이 작을 때만 중심값과 거의 같습니다(편향 ≈ O((Rr/r)²)). Rr을 키우면 분산은 줄지만 공간 해상도와 편향이 커지므로, STEP 3에서 민감도를 측정해 기본값을 정합니다(초기 가정 0.5 m, 미확정).
  • 수신 구가 표면과 겹치면 구의 일부가 벽 뒤에 있어 편향됩니다. 구와 표면의 거리가 Rr보다 가까우면 경고합니다.
  • 벽에 막히지 않고 탈출하는 마지막 구간도 반드시 집계합니다(tfar = 장면 대각선 × 충분한 배수).
  • 공기 흡음은 구간 안에서 연속적으로 변하지만, 수신 구가 작으므로 구간 중점의 누적 경로 길이에서 식 (5.1)을 적용합니다. 근사

9.2 해석식 + 몬테카를로 혼합과 중복 집계 방지

점음원의 직접음과 초기 정반사는 해석식으로 정확히 구하고, 확산 성분만 몬테카를로로 구하면 잡음이 줄어듭니다. 이때 같은 에너지가 두 번 더해지지 않도록 경로 종류별로 담당을 나눕니다.

경로 종류계산 방식몬테카를로 집계
직접음 (nSpec = 0, nDiff = 0)해석식 (4.1)제외
정반사만, 차수 ≤ Kimg이미지 소스 (7.5)제외
정반사만, 차수 > Kimg몬테카를로 (9.2)집계
확산 1회 이상 포함 (nDiff ≥ 1)몬테카를로 (9.2)집계
집계 조건: nDiff ≥ 1 또는 nSpec > Kimg (9.5)

이 규칙은 모든 경로가 정확히 한 번씩 세어지게 합니다. 합계(직접음 + 이미지 소스 + 몬테카를로)의 일관성은 STEP 3에서 "s = 0이면 STEP 2와 일치"로 검증합니다.

9.3 불확실성 표시

N개의 레이를 B개 배치(기본 10)로 나누어 배치별 추정값의 평균 m과 표준오차 SE = σ / √B를 구해, 수신점마다 상대 표준오차와 dB 변동폭을 표시합니다. 상대 표준오차가 기준(예: 10 %)을 넘으면 경고합니다.

상대 변동 ≈ 10 log10( 1 ± SE / m ) [dB] , SE ∝ 1 / √N (9.6)
레이 수 N평균 / 해석해단일 실행 상대 표준편차10회 반복 범위 [dB]
10,0001.08211.4 %-0.27 ~ +1.15
100,0000.9995.3 %-0.53 ~ +0.25
1,000,0001.0002.1 %-0.16 ~ +0.12

자유장, Rr = 0.5 m, r = 5 m, 배치 10회 기준입니다. 상대 표준편차는 N에 대해 약 1/√N으로 줄어듭니다. Normal 프리셋의 1차 레이 10,000개로는 이렇게 단순한 자유장에서도 작은 수신 구의 결과가 수 dB의 1/10~1 dB 수준으로 흔들립니다. 다중 반사 경로에서는 변동이 더 커지므로, 직접음·초기 반사를 해석식으로 분리하는 설계(9.2)가 필요합니다.

10. 시간 영역과 시각화의 물리적 정의

세 가지 뷰(정상상태 컬러맵, 파면 애니메이션, 에코그램)는 같은 추적 데이터에서 만들어집니다. 화면에 보이는 값이 무엇을 뜻하는지 아래처럼 정의합니다.

10.1 도달 시간과 에코그램

경로 길이 L인 점에는 t = L / c에 도달합니다. 음원이 에너지 E0인 임펄스를 방출하고 각 레이가 에너지 패킷 ei = E0/N(× 흡수 가중)을 운반한다고 보면, 시간 구간 k(폭 Δt)의 평균 에너지 밀도는 다음과 같습니다.

wk = ( 1 / ( V Δt ) ) Σi ei τi,k , τi,k = ℓi,k / c (10.1) τi,k는 패킷 i가 구간 k 동안 수신 영역에 머문 시간, ℓi,k는 그 구간에 해당하는 경로 길이입니다.
Lrel( x, tk ) = 10 log10( wk / wref ) , wref = E0 / ( 4π · (1 m)² · c Δt ) (10.2) wref는 같은 Δt로 평균한 자유장 1 m 지점의 에너지 밀도입니다. 파면이 구간 안에 완전히 들어오면 직접음은 정확히 −20 log10 r이 됩니다.
  • 에코그램의 시간 적분은 정상상태 값 (9.2)와 일치해야 합니다(검증 항목).
  • Δt는 파면이 시간 방향으로 번지는 두께(c·Δt)를 정합니다. 격자 셀 크기 h에 맞춰 Δt ≈ h / c로 시작합니다(결정 D17, 잠정).

10.2 단면 컬러맵

수신기 높이의 수평 단면을 한 변 h인 정육면체 셀의 격자로 나누고, 각 셀을 수신 영역(V = h³)으로 씁니다. 셀 안의 경로 길이는 선분–박스 교차(slab 방법)로 구하고, 식 (9.2) 또는 시간 구간별 식 (10.1)을 적용합니다. 직접음과 이미지 소스 성분은 셀 중심에서 해석식으로 계산합니다.

10.3 파면 애니메이션

  • 시간 t에서 각 경로 위 입자의 위치는 누적 경로 길이가 c·t인 지점입니다. 입자 수천 개가 구형 파면처럼 보입니다. 표시용 입자 수는 계산 레이 수와 별개로 정할 수 있습니다.
  • 입자 색은 입자의 에너지가 아닙니다. 거리 감쇠는 입자 에너지가 줄어서가 아니라 입자 밀도가 줄어서 나타나기 때문입니다. 입자 색은 그 위치의 국소 에너지 밀도 추정(식 10.2의 Lrel)에서 얻습니다.
  • STEP 1~2: 직접음은 Lrel = −20 log10 r − Aair, 정반사는 이미지 소스의 펼친 경로 L로 Lrel = −20 log10 L + 10 log10 Π(1−α)(1−s) − Aair를 씁니다. 이 경우 파면이 이미지 소스에서 나온 구면이므로 정확한 식입니다.
  • STEP 3~4: 확산이 포함되면 파면이 흐트러지므로, 입자 위치 주변의 입자 에너지를 커널로 합산하는 국소 밀도 추정으로 색을 정합니다.
  • 이 애니메이션은 에너지 패킷의 전파이며 압력 파형이 아닙니다. 위상, 간섭, 정재파, 회절은 나타나지 않습니다.

10.4 표면 입사 에너지

삼각형(또는 면 묶음) 면적이 A일 때, 정상상태에서 입사 세기는 충돌한 레이의 파워 합을 면적으로 나눈 값입니다.

Is = Σhits Pi / A , Lsurf = 10 log10( Is / ( W / 4π ) ) (10.3) 직접음·이미지 소스 성분은 해석식 I cos θ, 확산 성분은 충돌 누적으로 계산합니다(9.2의 분담 규칙과 같음).

11. 전체 알고리즘 (의사코드)

입력: 메시+재료, 음원 W_b, 수신점/격자, 설정 {N, K_max, K_img, R_r, seed}
전처리: 단위 변환(→ m), BVH 구축, ε = 1e-6 × 장면 대각선

for 밴드 b in 6개 밴드:
    // (1) 해석 성분
    I_direct[x] = W_b / (4π r²) · 10^(−α_air,b r / 10) · visible(S, x)        // (4.1), (5.1)
    I_image[x]  = Σ 유효 이미지 경로(차수 ≤ K_img) (7.5)

    // (2) 몬테카를로 성분 (확산 포함 / 고차 정반사)
    rng = PRNG(seed, b)
    for i in 0 .. N−1:
        O = S;  d = uniformSphere(rng);  P = W_b / N
        L = 0;  nSpec = 0;  nDiff = 0
        for k in 0 .. K_max:
            hit   = bvh.closest(O, d)
            t_end = hit ? hit.t : t_far                                       // 탈출 구간도 집계
            if (nDiff ≥ 1 or nSpec > K_img):                                  // (9.5)
                accumulate(O, d, t_end, P, L)   // 수신 구/셀, 에코그램 시간 구간, 표면 입사
                                                // (구간 중점 경로 길이로 공기 흡음 적용)
            if (!hit or k == K_max) break
            L += t_end;   P *= (1 − α_b)
            if (rng() < s_b) { d = cosineSample(n, rng); nDiff++ }           // (8.2)
            else             { d = reflect(d, n);        nSpec++ }           // (7.1)
            O = hit.point + ε · n

    I_mc[x] = (1 / V) Σ P_i ℓ_i  (배치별 → 표준오차)                            // (9.2), (9.6)

// (3) 합성과 출력
I_total  = I_direct + I_image + I_mc
L_rel,b  = 10 log10( 4π I_total / W_b )                                         // (4.5)
L_rel,tot = (4.6)

14. 한계와 가정

  • 기하음향 근사입니다. 위상, 간섭, 실내 모드, 정재파, 회절(STEP 5 전)은 계산하지 않습니다.
  • 산란은 Lambert 분포로 근사하고, 재료는 밴드별 α, s 외의 주파수 상세 특성이 없습니다.
  • 대기는 균질하며 굴절·바람·온도 구배·지면 임피던스(지면 효과의 위상 성분)는 다루지 않습니다.
  • 재료 라이브러리는 신뢰할 수 있는 밴드별 데이터가 확보되기 전까지 "예시 프리셋"입니다.
  • "80% 일치"는 목표이며 달성 주장이 아닙니다. 검증 데이터와 판정 기준이 정해진 뒤에만 사용합니다.
  • 검증 전 결과는 UI에서 "미검증 프리뷰"로 표시하며, 검증된 SPL 예측과 구분합니다.
  • 실행 시간은 하드웨어 측정 전에 약속하지 않습니다(STEP 6에서 벤치마크).

17. 해석 영역(박스 룸)과 경계 조건 (STEP 2)

모든 장면은 박스 모양 해석 영역 안에서 계산합니다(기본 10 × 10 × 10 m). 6개 면 각각에 경계 조건을 줍니다.

  • 반사(실내): 재료의 흡음률 α(f)를 적용한 정반사 면입니다. 정반사 에너지 계수는 (1 − α)(1 − s)이며 산란분 s는 STEP 4의 확산 반사(21장)에서 다룹니다. 근사
  • 소산(열림): α = 1로 취급해 정반사 계수가 0이고, 이 면을 지나간 광선·경로는 사라집니다. 열린 공간을 박스로 근사하는 방식이며, 박스 밖에서 되돌아오는 에너지는 없다고 가정합니다.

임포트한 STL/OBJ는 이 영역 안의 객체입니다. 객체는 차폐·반사·회절의 대상이고, 영역 면은 차폐 판정에 쓰지 않습니다. 재료 값은 예시이며 실측 데이터가 아닙니다.

18. 정반사: 이미지 음원법 (STEP 2)

차수 1~3(기본 2)까지 평면 반사를 이미지 음원으로 구성하고, 각 경로를 실제 삼각형 위에서 검증합니다(반사점이 면 안, 각 구간이 가려지지 않음). 경로 길이 L의 레벨은 직접음과 같은 거리 감쇠·공기 흡음에 반사 계수 곱을 적용합니다.

Grefl(f) = Πk (1 − αk)(1 − sk) · g(L, f) (18.1) 기준식 이미지 음원법 자체는 기준 방법입니다. 성분 합산은 비간섭(에너지 합)이므로 근사입니다.

한계: 경로 수 상한(6000)을 넘으면 차수를 낮추고 UI에 경고합니다. 차수를 넘는 후기 반사(잔향)는 포함하지 않아 닫힌 방에서 레벨이 낮게 나옵니다. 곡면은 삼각형 평면의 집합으로 취급합니다.

19. 회절: 차폐 보정 (STEP 2)

직접음이 객체에 가려진 수신점에 대해 ISO 9613-2의 차폐 감쇠를 적용합니다. 파장 λ = c/f, 음원→(모서리들)→수신점의 최단 경로 길이와 직선 거리의 차를 경로차 δ라 하면:

Dz = 10 log10( 3 + (40/λ) · C3 · δ · Kmet ) , C3 = ( 1 + (5λ/e)² ) / ( 1/3 + (5λ/e)² ) (19.1) 경험식 단일 모서리 상한 20 dB, 이중 모서리(두꺼운 벽) 상한 25 dB, Kmet = 1(기상 보정 없음). e는 두 모서리 사이 거리(단일이면 C3 = 1).

최단 경로는 평면 안에서 팽팽한 줄(taut string)로 찾습니다. 위·좌·우 경로를 후보로 하고, 상한에 걸린 경로는 합산하지 않으며(전부 걸리면 상한값 하나), 나머지는 에너지로 합칩니다.

한계와 편향

  • 가려진 곳에만 적용하므로 그림자 경계에서 약 4.8 dB의 불연속이 생깁니다(실제는 연속).
  • 반사 경로의 회절, 회절 경로의 반사는 포함하지 않습니다. 회절파는 파면 애니메이션에도 그리지 않습니다.
  • Kirchhoff/Fresnel 반평면 기준해와 비교하면 ISO/Maekawa형 식은 깊은 그림자에서 약 1.2~2.9 dB 덜 감쇠하는 경향이 있습니다(앱 테스트에서 확인).
  • 기하음향 가정상 약 100 Hz 이하는 신뢰할 수 없습니다. 이 구현은 검증된 해석 도구가 아니라 스크리닝용 근사입니다.

20. 다중 음원과 객체 재료 (STEP 3)

다중 음원. 음원이 여러 개이면 각 음원의 기여를 에너지로 합산합니다(비간섭, 근사). 서로 다른 음원의 위상 간섭은 계산하지 않습니다. 표시 레벨의 기준은 선택한 레벨(전체, A가중, 밴드)에서 가장 큰 음원의 자유장 1 m = 0 dB이고, 다른 음원은 Lw 차이만큼 에너지 비율 10ΔLw/10로 더해집니다. 음원이 하나이면 지금까지의 단일 음원 결과와 같습니다.

L = 10 log10 Σs ks Σb wsb gsb(r) , ks = 10(Lw,s − Lw,max)/10 (20.1)

객체 재료. 객체는 서페이스(열린 면 포함)이며 객체마다 밴드별 흡음률 α와 산란 계수 s를 가집니다. 역할(반사벽, 흡음재, 장애물, 소산벽)은 예시 프리셋일 뿐 실측 데이터가 아닙니다. 소산벽은 α = 1이므로 정반사 계수가 0이고, 광선은 그 면에서 사라집니다. 서페이스는 양면이며 법선 방향에 따라 달라지지 않습니다. 투과율은 지원하지 않으며(STEP 6), 얇은 서페이스는 완전 차폐로 취급됩니다.

Run. 계산은 Run 버튼을 누른 시점의 장면으로만 하고, 결과는 그 시점의 스냅샷으로 보관합니다. 이후 장면을 편집하면 결과는 "오래된 결과"로 표시되며 다시 Run 해야 갱신됩니다.

21. 확산 반사와 수신 구 추정자 (STEP 4)

역할 분담(이중 집계 방지). 직접음과 낮은 차수의 순수 정반사는 이미지 음원(18장)이 해석적으로 계산합니다. 몬테카를로(MC) 광선 추적은 그 나머지, 곧 (1) 확산 반사를 한 번이라도 겪은 경로와 (2) 이미지 음원이 쓴 차수를 넘는 순수 정반사 경로만 집계합니다. 두 방법이 같은 경로를 두 번 세지도, 빠뜨리지도 않도록 한 규칙입니다.

광선. 음원에서 등방(균일 구면)으로 광선을 쏘고, 밴드마다 독립으로 추적합니다. 표면에 닿을 때마다 에너지에 (1 − α)를 곱하고, 확률 s로 램버트(코사인 가중) 확산 반사, 확률 1 − s로 정반사합니다. 기댓값으로는 정반사 계수 (1 − α)(1 − s)와 확산 계수 (1 − α)s가 됩니다. 경로를 따라 공기 흡음 10−αr/10을 곱합니다.

수신 구 track-length 추정자. 반경 a, 부피 V의 구 안에서 광선이 지나간 길이 l과 그때의 에너지 e를 합산합니다.

GMC(f) = 4π · Σi ei li / V (21.1) 기준식 정상 상태에서 구 안의 에너지 밀도는 w = (1/V) Σ e l / c 이고, 자유장 1 m의 세기 P/(4π)로 정규화하면 위 식이 되어 G = (1 m / r)²가 됩니다(자유장 시험으로 확인). 구 반경이 유한하므로 구 안 평균의 편향이 있습니다.

슬라이스에는 같은 방식으로 영역을 나눈 3차원 복셀에 길이를 누적하고(Amanatides–Woo 순회), 복셀 중심 삼선형 보간으로 표시합니다. 복셀 크기가 곧 해상도이므로 기본 40셀(긴 변)의 거친 해상도입니다.

불확실성. 레이를 8개 배치로 나눠 배치별 이득의 표준오차(평균의 표준오차)를 구하고 결과 표에 ±dB로 표시합니다. 이는 통계 오차만 나타내며 모델 오차(확산 가정, 근사식, 재료 값)는 포함하지 않습니다 근사. 시드가 같으면 결과가 같습니다.

참조해와 시험. 모든 면이 램버트(s = 1)이고 흡음률 α인 볼록한 방에서 확산 반사 이후의 평균 이득은 평균 자유 행로 ℓ = 4V/S를 쓰면 G = 16π(1 − α)/(S α)입니다 참조(확산장 가정). 앱 시험은 이 값과 8 % 안에서 일치함을 확인했습니다. 에너지 수지(흡수 + 공기 + 중단 잔여 = 방출)는 1e-9 안에서 맞습니다.

한계. 광선 수가 적으면 확산 성분의 통계 오차가 큽니다(기본 밴드당 5,000개). 최대 반사 횟수와 하한 에너지(초기의 10−6)에서 추적을 멈추므로 흡음이 매우 낮은 방에서는 잔향 꼬리가 조금 잘립니다. 확산 반사 경로의 회절, 간섭, 시간 분해(에코그램)는 아직 없습니다(STEP 5).

22. 투과와 면음원 (STEP 6)

투과. 재료에 밴드별 투과 손실 TL [dB]을 주면 에너지 투과율 τ = 10−TL/10으로 바꿔 쓰고, α + τ ≤ 1이어야 합니다(위반 시 오류). TL을 비우면 τ = 0(완전 차폐)이며 이전 결과와 같습니다. 반사 에너지는 (1 − α − τ)이고 그중 산란 계수 s가 확산으로 갑니다. 정반사 계수는 (1 − α − τ)(1 − s)입니다 근사.

직접음: G = (1 m / r)² · 10−αr/10 · Πj τj (가로지른 면 j마다 한 번) (22.1) 기준식 평면 하나를 통과하면 τ, 두 장이면 τ². 몬테카를로 광선은 확률 τ/(1 − α)로 면을 그대로 통과하며 가중치는 바꾸지 않습니다.

이중 집계. 직접 투과(반사 0회)는 위 해석식이 집계하므로 MC는 세지 않습니다. MC는 투과 후 반사된 경로만 집계합니다. 이미지 음원 반사 경로는 투과 면을 만나면 막힌 것으로 처리합니다(투과 후 반사 경로는 MC가 맡음). 파면 재생용 광선은 투과를 무시합니다. 투과는 면 두께·회절·모드 결합을 다루지 않는 에너지 모델입니다.

면음원. 평면 객체에 전체 파워 레벨 Lw를 주고 가로 nu × 세로 nv(각 1~5)로 나눠 셀 중심에 점음원을 둡니다. 점당 Lw − 10 log10(nunv)이므로 파워 합이 보존됩니다. 표본점은 전방위(등방) 비간섭 점음원이며 면 자체는 소리를 막거나 반사하지 않습니다 근사. 가까운 거리에서는 표본점 수가 적으면 면의 크기 효과가 거칠게 나옵니다.

23. 에코그램과 표면 입사 에너지 (STEP 5)

에코그램. 수신점마다 시간 구간(기본 2 ms, 400 ms까지)별 에너지 이득을 쌓습니다. 직접음(투과 포함)은 거리/c, 이미지 음원 경로는 경로 길이/c, 회절은 (직선거리 + 최소 경로차 δ)/c의 구간에 해석적으로 넣고, 확산·고차 성분은 MC 광선이 수신 구를 지나간 시각별 길이로 쌓습니다. 모든 구간의 합은 총 이득과 같습니다(시험). 회절 에너지는 가장 짧은 우회 경로 시각에 모아 표시하므로 시간 번짐은 표현하지 않습니다.

표면 입사 에너지. 면 삼각형 하나에 광선이 닿을 때 에너지를 쌓아 Gtri = 4π Σ e / A로 정규화하고(자유장에서 1/r²가 됨, 시험) dB로 색칠합니다. MC로만 구하므로 확산 계산이 켜져 있어야 하며, 삼각형이 작으면 통계 잡음이 큽니다. 영역 경계면에는 적용하지 않습니다.

내보내기. CSV(결과 표, 에코그램, 슬라이스), 3D 뷰 PNG, 재생 GIF(프레임 수·가로 폭·간격 선택, 시각과 컬러바 표기). 모두 상대 레벨이며 미검증 값입니다.
